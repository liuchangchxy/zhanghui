# 全局写作铁律（违反任何一条即打回重写）

## 铁律一：句长必须参差

- 每500字内必须有1句5字以下的短句/断句
- 每500字内必须有1句25字以上的长句
- 段落长度以1-3行为主，极少超过5行；长段落（5行以上）每章不超过2段
- 禁止连续3段以上使用相同句式节奏
- 一句话不超过50字，超过必须按动作/视线/情绪变化断开
- 先写主干动作，再补心理、原因和状态
- 形容词要精准，一句话里1-2个足够
- 禁止故意堆砌辞藻，用最简单最精准的词说清意思

## 铁律二：禁止情绪标注

只写身体反应，不写情绪结论。以下词汇/句式禁止出现在正文中（角色台词除外）：

| 禁止写法 | 替代方案 |
|---------|---------|
| 心里一沉/感到恐惧 | 手指收紧、呼吸变浅、指甲掐进掌心 |
| 她/他明白了 | 让角色用行动回应 |
| XX的眼神变了 | 瞳孔收缩、眨眼频率变化、目光移动 |
| 气氛凝重/紧张 | 写一个具体的声音/气味/触感 |
| 恐惧像XX | 不写"恐惧"二字，只写身体和行为 |
| 他笑了/苦笑/冷笑 | 嘴角只动了一边、牙齿咬着下唇内侧 |

**核心原则：** 只写身体，不写心理。只写现象，不写结论。

## 铁律三：对白不能承载设定

- 角色不会在对话中解释世界观/规则/背景
- 角色说话时有情绪遮掩，不会条理清晰地说明一切
- 重要信息通过动作、发现、冲突来展示
- 删掉"原来""也就是说""这说明"等总结性句子
- 禁止把"他明白了"换成"他意识到"——必须改成物证、动作受阻、体感反馈或选择后果
- 一句台词如果删掉不影响情节，就应该删掉
- 对白占比控制在40%-55%
- 人物辨识度：遮住名字读台词，分不清谁在说话就要重写
- 反派对白要比现实更极端——用数字对比、公开羞辱制造愤怒
- 互动感：对白核心是"回应"不是"轮流发言"；允许打断、追问、抢话、吐槽
- 每段关键对白至少承担一种功能：给新信息、造冲突、做决定、改关系、推行动
- 潜台词：越重要的情绪越不要第一句说破

## 铁律四：比喻必须带有个人印记

比喻必须反映角色的出身、职业、经历。禁止通用型比喻。

| 角色背景 | 禁止 | 应该 |
|---------|------|------|
| 语文老师 | 恐惧像冰冷的手 | 恐惧像交卷铃响了，卷子还空白 |
| 补天小吏 | 沉默像铅 | 沉默像账本上被涂掉的那一行 |
| 修复师 | 时间凝固了 | 时间像卡死的齿轮，咬着不动 |
| 县城临时工 | 黑暗吞噬一切 | 黑得像档案室最底层那个没编目的箱子 |

## 铁律五：段落结构必须不可预测

交替使用以下段落类型，禁止连续3段同类型：
- **纯动作段**：只有动词和名词，没有形容词和内心描写
- **纯对话段**：两人以上的快速对白，不插入动作描写
- **纯感知段**：只有五感描写
- **回忆闪回段**：用1-2句插入过去
- **独立短句段**：一句话单独成段

## 铁律六：每章必须有一个"不完美瞬间"

主角不能每章完美应对。至少选一个：
- 主角判断失误 / 情绪失控 / 方案有副作用
- 主角伤害了盟友 / 选择了"不那么对但更现实"的路

## 铁律七：反AI痕迹规则

### 均值回归禁区
- 禁止选"最常见"的情节走向——读者能猜到下一步就必须换
- 禁止通用型描写——"美丽的女孩""破旧的屋子"必须换成场景独有的具体细节
- 禁止万事顺遂——主角方案不能每次都成功，配角不能每次都配合

### 排比与平行结构禁区
- 最多两个并列，第三个必须换句式（禁止三连排比）
- "不是…而是…"每章最多一次
- 禁止"这不仅仅是…更是…""既是…也是…""不仅能够…还能够…"

### 分析与拔高禁区
- 禁止叙述者跳出来分析"这说明了什么""这反映了什么"
- 禁止把普通事件拔高成"关键时刻""历史性时刻"
- 禁止鸡汤——"相信自己""只要努力就能成功"
- 禁止含糊归因——"有人说""业内普遍认为""众所周知"
- 禁止辩证回避——"这既带来了机遇，也带来了挑战"；作者必须有立场

### 空心句禁区
删掉后读者什么信息都没损失的句子，就是空心句，必须删。
- "我们应该从多个角度出发"——删掉
- "采取科学合理的措施"——删掉
- "在一定程度上提升了效率和质量"——删掉

### 过渡与结构禁区
- 禁止：与此同时、值得注意的是、不可否认、毋庸置疑
- 禁止：首先…其次…最后…
- 禁止：随着…的不断发展、近年来、在当今社会、众所周知
- 禁止：综上所述、总而言之、未来，随着…的不断进步
- 禁止结局太圆满——留一个没解决的小尾巴

### 完美度禁区（太干净=AI）
- 允许角色犹豫、口误、改口
- 允许叙述有轻微跳跃
- 允许场景长度不完全对称
- 允许角色犯低级错误
- 禁止每个场景都有"意义"

### 情绪禁区（太平稳=AI）
- 禁止全章情绪平稳——必须有高峰和低谷
- 禁止用"客观来看""总体而言"开头
- 角色必须有态度——不能对所有人中性
- 每章至少有一次情绪突变——不是渐变，是突然的转变

### 具体性禁区（只有概念没有现场）
- 每个重要场景至少2个具体物件、1个具体时间或地点、1个感官细节
- 动作必须具体：不是"他看了看"，是"他用手背擦了一下鼻子"

### 句式禁区
- 禁止连续3句以同一个字开头
- 禁止段落之间长度过度对称
- 禁止每个段落都有完整起承转合

### 高频AI词禁用表（正文不得出现，角色台词除外）
```

强调/突出其重要性/意义、反映出更广泛的
标志着其持续/持久地、做出贡献、奠定基础、标志着/塑造
```
