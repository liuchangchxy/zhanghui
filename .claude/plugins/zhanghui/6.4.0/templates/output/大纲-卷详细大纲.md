# 第 {volume_id} 卷 详细大纲

> 本卷为第 {volume_id} 卷的逐章大纲，每章独立成节。
> 卷级结构遵循 `大纲-卷节拍表.md` 的 15-Beat；每章内部采用 Dwight Swain Scene-Sequel 框架。
> **BLOCKER 字段**：scene_goal / scene_conflict / sequel_decision 必须 filled
> **WARNING 字段**：scene_setback / scene_resolution / sequel_reaction / sequel_dilemma 建议填

## 章节模板

每章按以下模板填写：

```markdown
## 第{N}章：[标题]

**目标**：{一句话写清本章主角目标}
**阻力**：{谁/什么阻碍，目标被何种力量阻挡}
**代价**：{主角为达成目标需要付出的代价/风险}
**核心冲突**：{本张冲突的核心矛盾点}

**反派层级**：{小障碍/中障碍/小BOSS/BOSS}

**本章变化**：{本章结束时主角/局势发生了何种不可逆变化}
**未闭合问题**：{本章留下、必须在下章/后续解决的问题}
**钩子**：{章末一句话钩子，引出下一章}

**新增 craft 必填字段**：

- **beat_position**：本章在卷 15-beat 中的位置（如 Midpoint / Fun and Games）
- **scene_goal**：Scene 4 步的主角目标
- **scene_conflict**：Scene 4 步的阻碍
- **scene_setback**：Scene 4 步的挫败（建议填）
- **scene_resolution**：Scene 4 步的暂时结果（建议填）
- **sequel_reaction**：Sequel 3 步的主角反应（建议填）
- **sequel_dilemma**：Sequel 3 步的主角困境（建议填）
- **sequel_decision**：Sequel 3 步的主角决定 = 下章目标
- **hook_type**：6 种章末钩子之一（悬念式/反转式/情绪炸弹式/信息投放式/留白式/反讽式）
- **foreshadow_buried**：本章埋设的伏笔 ID 列表
- **foreshadow_paid_off**：本章回收的伏笔 ID 列表
```

## 字段填写说明

### 基础字段（保留旧版结构）
- **目标/阻力/代价**：从主角视角出发，缺一不可
- **核心冲突**：必须包含"对抗双方"和"对抗内容"
- **反派层级**：按出场的对手层级填写（无对手写"无（仅环境/内心）"）
- **本章变化**：必须是不可逆变化，不是"想了想/看了看"
- **未闭合问题**：必须是具体可回答的问题，而非"接下来如何"
- **钩子**：必须是原话或类原话的具体台词/旁白

### 新增 craft 必填字段（Scene-Sequel + beat + hook + foreshadow）
- **beat_position**：与 `大纲-卷节拍表.md` 的 15 Beat 对齐；多个 beat 选本章主 beat
- **scene_goal / scene_conflict**：本 Scene 的目标与阻碍，缺一即触发 BLOCKER
- **scene_setback / scene_resolution**：挫败与暂时结果；纯爽章可写"无明显 setback"
- **sequel_reaction / sequel_dilemma / sequel_decision**：主角的情绪反应 → 困境 → 决定；sequel_decision 是下章 scene_goal 的种子
- **hook_type**：章末钩子类型，6 选 1（悬念式/反转式/情绪炸弹式/信息投放式/留白式/反讽式）
- **foreshadow_buried**：本章埋设的伏笔 ID（与 `大纲-总纲.md` 的伏笔表 ID 对齐），无则写"无"
- **foreshadow_paid_off**：本章回收的伏笔 ID，无则写"无"

## 章节示例

```markdown
## 第4章：迦南学院的考验

**目标**：萧炎参加迦南学院入学测试，证明自己并非废材。
**阻力**：测试官韩越对萧炎的废材名声嗤之以鼻，测试难度被故意提高。
**代价**：展露部分实力等于暴露修炼恢复的秘密，可能引来觊觎药老戒指的势力。
**核心冲突**：隐藏实力保全秘密 vs 全力以赴证明自己。

**反派层级**：韩越（小障碍级）。

**本章变化**：萧炎通过测试，但长老注意到他身上的异常气息。
**未闭合问题**：长老是否认出了药老戒指？这会带来什么后果？
**钩子**：长老在萧炎离开后，自言自语："这股气息……不可能……"

**新增 craft 必填字段**：

- **beat_position**：Catalyst（第 4 Beat，主角被迫接受新任务）
- **scene_goal**：萧炎通过迦南学院入学测试
- **scene_conflict**：测试官韩越刻意刁难，难度被人为提高
- **scene_setback**：测试中途险些暴露药老气息，引发长老关注
- **scene_resolution**：萧炎惊险通过测试，但留下气息暴露的隐患
- **sequel_reaction**：萧炎表面镇定，内心对长老的注视极为警惕
- **sequel_dilemma**：继续隐藏实力 vs 主动交出戒指自保
- **sequel_decision**：保持低调，先调查长老是否可信再行动
- **hook_type**：悬念式（长老独白："这股气息……不可能……"）
- **foreshadow_buried**：FS-001（药老气息外泄被长老察觉）
- **foreshadow_paid_off**：无
```
