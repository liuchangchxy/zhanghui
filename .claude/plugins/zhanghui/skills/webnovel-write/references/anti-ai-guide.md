# Anti-AI 写作与审查防癖好参考工具箱 (Heuristic Catalogue)

> 核心定位：局部经验启发式参考（Heuristic Tools），供创作初稿与审查诊断参考。
> 注意：本文件非全局强制清盘宪法。保留局部有效启发，削弱全局硬性变换；禁止强行将全文拆散成单句短段或抹杀所有自然直接情绪。

## 常见 AI 癖好与诊断启发

作为 LLM，你在写作时容易出现以下倾向。创作与诊断时应予以关注：

1. **每段写完整闭环**——倾向于"起因→经过→结果→感悟"四段走完。可适度删掉感悟，留未解决的余味。
2. **用副词修饰一切**——倾向于写"缓缓开口""淡淡说道""微微点头"。可删掉副词，用具体动作替代。
3. **所有角色同一套反应**——倾向于让每个人都"瞳孔微缩""心中一凛"。应给角色设计差异化反应。
4. **对话像辩论赛**——倾向于让角色完整、理性地表达观点。可让角色说话带潜台词、省略和打断。
5. **情绪机械公式化**——避免走向另一个极端，不要把所有情绪都套进"生理反应+微动作"模板。允许合理的直接情感宣泄与内心独白。
6. **信息过密与电报体**——避免通篇单句成段，保留中长句的沉浸呼吸感。
7. **展示后解释**——用动作展示后，再补一句旁白解释。可删掉解释句，信任读者的理解力。

## 替代方案速查表

| AI 癖好 | 启发方向 | 示例 |
|---------|---------|------|
| 泛滥的"他感到愤怒" | 结合动作与处境 | "指节捏得发白，舌尖尝到铁锈味。再等一秒他就动手。" |
| 泛滥的"缓缓说道" | 删副词，加自然动作 | "他把杯子搁下——'你确定？'" |
| "眸中闪过一丝X" | 个性化行为 | "她咬了下嘴唇内侧"（紧张） / "他开始拧笔帽"（焦虑） |
| "心中暗道" | 直接写内心句 | 删掉"心中暗道"四个字，后面的内容直接保留 |
| 四段闭环 | 截断在高点 | 删掉最后的感悟句，让读者自己体会 |
| 全员书面语 | 口语化+个人口癖 | 加口头禅、省略、打断，区分口吻 |
| 段末总结 | 删总结句 | 用动作或对话结尾，不写"他终于明白了" |
| 展示后解释 | 删解释句 | 写完"她把门摔上"后不要再写"她显然很生气" |
| "更重要的是……" | 直接说事 | 删掉递进模板词，直接给信息 |

## 对话专项

好的对话特征：
- 有人抢话、有人沉默、有人答非所问
- 角色不会把真实想法全盘托出
- 不同角色有不同的说话节奏（有人啰嗦、有人惜字如金）
- 动作引导自然，不机械堆砌 said tag

坏的对话特征：
- A说→B说→A说→B说，严格交替
- 每句都完整回应上一句
- "XX说道""XX淡淡道"贯穿全篇
- 角色说话像在做报告或念说明书

## 节奏专项

好的节奏特征：
- 有长句有短句，疏密得当
- 紧张激烈处节奏紧凑
- 平静铺垫处保留完整段落与意境烘托
- 杜绝口吃碎切的电报体
