# 第四轮结果：Lean 连续性事实块 + 写后 show-then-explain 修复

- 分支：`feat/writer-freedom`
- 样本：ch6 / ch7 / ch10（与第三轮相同，未换样）
- 对照：A = 原正式基线（第三轮归档，逐字节复用）；B = 本轮 lean + 硬事实受保护区 + lean Skill + `## 本章相关既有事实` + 写后 show-then-explain
- 盲评：每章 2 位新评委，X/Y 随机换位、阅读顺序相反，13 项同一把尺（11 正向 + 2 反向）

## 结论

**`LEAN_CONTINUITY_SUPPORTED_POSTEDIT_NEUTRAL`**

1. **连续性恢复了。** ch10 从第三轮 B 的 `1 critical + 4 high`（严重度加权 24）回到 `0 critical / 0 high`（11），与 A 完全同档；ch7 的潮位方向和数字关系对上了，上章约定也接上了。
2. **写后修复没有产生文学收益，因为它一次都没触发。** 三章 B 稿 `detected 0 / applied 0`。A 稿上同一检测器能命中并完成删除（正对照，见 §7），所以不是管线坏了，是 B 稿里没有它认识的那种句式。
3. **代价是文学质量下降。** 盲评调整均分 A 7.97 / B 7.23，选稿 A 4 : B 1；「作者直接解释」A 7.58 / B 6.33，比第三轮的 −0.75 又掉到 −1.25。连续性块把该说的事实说清了，也让正文更像在逐条交代。

## 2. 写作前：连续性块的生成

来源只有两处，都是已存在的受治理来源，没有新库、新 Agent、第二次 Context：

- **已 accepted 章节正文**（`_accepted_prose_by_chapter(chapter)`，只取目标章之前 accepted 的 `draft.md`）里的地点/物品句；
- **现有 Canon**（`governed_canon.canon_items`）里的 `world_rule_revealed`、关系条目、实体属性字段。

选择顺序（`select_continuity_facts`）：

| 层 | 内容 | 上限 |
|---|---|---|
| 1 | 每个地点/物品一句设定句，取最早出现的 accepted 章；8–80 字；必须含"在/位于/门口/登记/凭/须/开放/能进/楼"等设定标记；**排除含角色名的句子**（那是场景动作，不是设定）；排除"的时候/走出/回到/离开/他说/他想/他问" | 170 字/条 |
| 2 | `world_rule_revealed` 的 `rule_content`，新章优先 | 170 字/条 |
| 3 | 关系条目，实体 id 换成姓名 | 110 字/条 |
| 4 | 实体属性字段（`attributes.*`），**只在 id 能映射到姓名时输出** | 110 字/条 |

总预算 700 字（实际 479），超预算就整条丢弃，不做截断拼接。块渲染成 `## 本章相关既有事实`，带一句边界说明（"本节不包含本章的剧情目标"），插在 `## 本章必须写对` 之后。同一批 `world_rule_revealed` / 关系 / 属性不再在 `【已确认前文事实】` 里重复出现。

**块内容（三章相同，479 字，7 条）：**

```
## 本章相关既有事实
（本节是本书前文已经确认、本章会用到的具体事实。地点、流程、物品、人物关系一律照此，
不要重新发明，也不要改写；本节不包含本章的剧情目标。）
- 地方志办公室在城西，一栋老楼的三层，下午两点半开门。
- 旧报库在报社后院，门口一本登记簿，写上日期就能进。
- 档案科的限制查阅卷宗须科级以上签字才能调阅；申请在系统里走，谁批的、谁看的都有记录；
  按卷宗等级，签完还要备案。经办人的原话是"录进去的东西，该看见的都能看见"。
- 地方志办公室阅览室与报社旧报库对普通查阅者开放：地方志凭阅览单、旧报库在门口登记簿
  写下姓名与进库时间即可查阅，不需要授权，也不与档案系统的调阅记录关联。
- 档案科流程：资产清点遇台账与实物不符须填差异说明，差异说明需要一份可以参照的原始登记；
  调阅不在本次清点范围内的材料须先走调阅申请；进站与离站都要在钥匙交接册的进出登记栏各签一次。
- 许知远 与 老周：放行但限制逗留："核完就走，别在站里转"，允许搬开两箱记录纸后仍要求
  放回原位，并站在门口看着他
- 许知远 与 梁沐：初次接触/信息提供者：外包检修工，主动透露"那批设备是事故之后统一换的"
```

来源：前两条来自第 2 章 accepted 正文；第 3–5 条来自 Canon（第 1、2 章的 `world_rule_revealed`）；
两条关系来自 Canon 第 2 章关系条目。

**已知瑕疵：** 最后一条把 Canon 的关系类型标签"初次接触/信息提供者"原样带了出来，
这是内部标签外泄，违反本轮约束的精神（虽然不含 id、不含路径）。本轮保留原样，
因为三份草稿就是照这一版写的；修法是在关系条目的渲染里去掉第一个"："之前的类型前缀。

## 7. show-then-explain：命中数 / 实际修改数

| 章 | A 命中 | B 命中 | B 实际修改 |
|---|---|---|---|
| ch6 | 0 | 0 | 0 |

**三章 B 全是 `NO_CHANGE`**：字数 3870 / 3930 / 4623，前后一致。

**正对照（证明修复链路通）：** 把同一命令跑在 ch7 的 A 稿上，检测到 1 条并完成局部删除，
质检门禁 `ACCEPTED`：

```
detected 1 / applied 1 / skipped 0
removed: ["他知道这一栏填不上。"]
4735 字 -> 4725 字   gate: ACCEPTED
```

产物：`scores/ch7/postedit_control_A.json`。

**为什么 B 稿上是 0：召回不足，不是病灶消失。** 同三份 B 稿里，盲评评委点出来的
"替读者下判断"的句子仍然存在，但都不在检测器的框架词表里：

- ch10："这句话不该说。" / "这句话比关门还轻，却把话说死了。" / "许知远听出，这句话挡的不是问题，是他这个人。"
- ch6："这句话是提醒，也是挡。"

按"这句话…"这一族统计：A 三章 5 处、B 三章 9 处（ch10 单章 B 5 / A 0）。
检测器只认"也就是说 / 他终于明白 / 他知道 / 原来"这类框架，抓不到"用一句话给上一句下结论"这种更常见的形态。
**这是本轮最实在的遗留缺陷。**

没有顺手扩词表：扩了就会去删"这句话不该说"这类交界句，而分不清它到底是重复解释还是人物当场判断——
本轮约束要求保留人物自己的判断，扩词表会把这件事做坏。

## 11. 归因边界

1. n=3 章、每章 2 位评委、单一 Reviewer，且本轮的 B 稿是**新写**的（不是改稿），
   评委的分数里既有"连续性块"的影响，也有一次重新起草本身的方差。上一轮同一对照是 3:3，
   本轮 4:1，方向一致但幅度受样本量限制。
2. 连续性恢复的证据是硬验收项 + Reviewer 分档，不依赖盲评；这一半比文学分稳。
3. "写后修复"这一半**没有真正被测试**：它在 B 稿上 0 命中。报告的
   `POSTEDIT_NEUTRAL` 只能读作"没有造成伤害"，不能读作"无效"。
4. Reviewer 与盲评都不是同一实例重复打分，绝对分不可跨轮直接比，只能比同轮 A/B 差。

## 12. 判定

`LEAN_CONTINUITY_SUPPORTED_POSTEDIT_NEUTRAL`

- 连续性：**支持**（ch7 方向/数字/约定；ch10 断档/地点/准入/介质/时间锚点全部通过；Reviewer 24→11）。
- 写后修复：**中性**（三章 0 命中 0 修改；正对照证明链路可用；召回不足是遗留缺陷）。
- 附带代价（不改变判定，但必须记）：盲评 7.97 / 7.23，选稿 4:1，作者直接解释再降 0.5。
