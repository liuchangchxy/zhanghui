# Hard Facts, Soft Craft — 第二轮 A/B 结果

**判定：`HARD_FACTS_SOFT_CRAFT_NEUTRAL`**

硬条件全部通过，B 臂没有把事实写错，也没有把 A 的控制力搞差。但文学质量没有变好：
六次盲评里 A 拿 4 次、B 拿 2 次，调整后均分 A 7.82 / B 7.49。B 唯一稳定赢下来的是
「人物声音」和「描写」，输得最多的是「潜台词」「作者直接解释」和两项反向指标。

这一轮的价值在硬条件：**「事实要硬」这部分是成立的，而且是在把 Writer prompt 砍掉
近一半的同时成立的。**「写法要松」这部分没有兑现在正文上。

---

## 1. 硬条件（先看这个）

必须先说清楚一件事：**这一轮 A 臂在这两个硬条件上也是对的。** 两臂都通过，所以硬条件
没有区分出 A 和 B——它区分的是「本轮的 B」和「第一轮的 B」。

| 条件 | 结果 | 证据 |
|---|---|---|
| ch7「复算比官方低约 1 米」方向不能丢 | **两臂均通过** | B：「比官方记录 4.96 米低了九十四公分」，并补「官方值高过主港、北岬两站」；A：「高潮三点四二对二点四八。九十四厘米。」数字本身正确（3.42 > 2.48），但没有用一句话说出哪边高 |
| ch10「年份连续性缺口」不能变成月份问题 | **两臂均通过** | B：「二〇一四，二〇一五，二〇一七，二〇一八……唯独少了二〇一六」；A：「二〇一六，空，二〇一八。中间少的是二〇一七。」两稿缺口类型都是年份，都没有出现「缺页/月份」式转述 |
| Canon / timeline / causality 不比 A 差 | **通过** | Reviewer 严重度加权：A 32 分 / B 25 分；high 级 A 1 条、B 0 条；logic 类 A 8 条 / B 2 条；timeline A 1 条 / B 0 条 |
| 受保护事实确实进了 prompt | **通过（B 独有）** | `## 本章必须写对` 在 B 三章 prompt 里都有（263–279 字），A 三章均无 |

真正有信息量的是纵向对比：**第一轮同样走 lean 的 B 把方向写反了**（复算 3.23 / 官方 2.31，
高出 0.92 米，Reviewer 判 high），本轮同一个受保护区让同样的 lean 设计写对了。所以
「受保护区能防住一错毁章」这个结论成立；「A 会写错、B 不会」这个结论**不成立**，
本轮 A 也没写错。

硬条件没有失败，所以这一轮不是 `FAILED`。

三处要如实说明的偏差：

1. **Brief 是唯一真正被硬门禁卡住的**。超 1800 字直接 `ValueError`，三章实测 1661–1777，
   没有触线。
2. **Skill 段反而变长了，而且逼近了预算上限。** 共享预算 1200 是按「预算内可容纳的正文」
   算的，但渲染时每条 Skill 还带着 `本章值得注意` 那段 Router 说明。实测 B 每章 1597–1738 字：
   其中 Router 说明 339–440 字，Skill 正文 1110–1153 字。也就是说 Skill 正文本身守住了
   1200，但**整段实际是 1.6–1.7k**，比 A 的「只有 Router 说明、不附 Skill 正文」长一倍多。
   横向比第一轮，B 的 Skill 段从 1890/2701/2420 降到 1738/1613/1597，**缩短了 8%–40%**，
   仍远高于 A。原因是 A 臂根本没有调用 `attach_skill_bodies()`——A 的 Skill 段只有 Router
   的一句话。这一点改写了第一轮的结论：第一轮说「Skill 原文进了 Writer」，那是对 **B 的
   上一版**成立，对 A 不成立。本轮 B 主动引入了 Skill 正文，是一个**新增内容**，不是
   「把重复删掉」。
3. **prompt 总量仍然降了 46–49%**，因为 Brief 和 Canon 的压缩幅度盖过了 Skill 段的增长。

### 两个反直觉结果，必须直说

1. **B 仍然「规则感」更重。** 「规则太多」A 4.50 / B 5.00（低分好），「生硬执行技巧」
   A 4.58 / B 5.42。这跟第一轮完全同向，而且差距比第一轮更大。B 的 prompt 少了一半字，
   评委却觉得它更像在逐条执行任务书。ch7 评委对两稿的原话就是「几乎逐条对应任务书」vs
   「多数化进一天的时间流」，而前者是 B。
2. **B 在「潜台词」上稳定落后（−0.67）。** 三名评委在 B 稿里点名了说破潜台词的具体句子：
   「他不是在挡许知远。他是在挡那本本子上的空白。」「他还有一层绕不过去的账」「这个念头
   他也放下了」。A 稿同类问题也有，但频率更低。

### 评委为什么选 B（ch7）

评委没有提到「保护事实」这件事——他们不知道哪一稿有受保护区。他们的理由是纯文学的：
X（=B）把证据链放进一天的跑动、等待和删改里，「判断与情绪都从动作长出来」，结尾停在
4.96 / 4.02 / 九十四公分上；Y（=A）证据链更完整，但标题提前给倾向、钩子后移、数据段报表化。

同一位评委给 A 列的三个问题里，两条是**控制问题**（梁沐「检修期」这条线没用、官方值
4.96 高过两邻站这个异常没点破），一条是文学问题（四连「划掉」像排除法）。

## 6. 风险与没做好的地方

1. **Skill 段变长**（见第 2 节）。这是本轮唯一的量级回退，且是我自己引入的：A 臂本来
   就不附 Skill 正文，本轮给 B 附上了。如果目标是「更短」，这一项应该重新考虑——要么
   把 Router 说明并入一行标题，要么只在 Router 真的选出「与本章强相关」的 2 个 Skill 时
   才附正文。
2. **Brief 的 1800 硬上限只在超线时才起作用。** 三章都没触线，也就是说「Brief 变短」
   这一半主要靠 Context Agent 自己写完就停，硬门禁只是兜底，没有被真正压测过。
3. **B 的 Router 说明逼近 120 上限**（3 条 ≥ 108）。上限有效，但没有余量；下一轮如果把
   上限降到 100，大概率会出现硬拒绝。
4. **样本 3 章、每章 2 名评委，n 太小。** 单维度差距全在评委噪声内，只有「选择次数」
   和「硬条件」这两类结果站得住。
5. **「写法要松」没有兑现。** 三章的正文都没变得更像「Jarvis 式自由写作」，反而在
   反向指标上更差。原因没有查清——可能是受保护区里「不得换成另一种说法」「以本节为准」
   这类措辞本身就在暗示「有检查表」，也可能只是 3 个样本的噪声。这一条留待下一轮。

## 7. 结论

- 「事实要硬」：**成立**。受保护区把 ch7 方向、ch10 缺口类型都钉住了，而且不靠 Reviewer
  兜底——正文本身就写对了。
- 「写法要松」：**没有成立**。prompt 短了 46–49%，Brief 短了六成，Router 说明短了三四成，
  正文的文学质量没有变好，反向指标反而更差。
- 因此判定 `HARD_FACTS_SOFT_CRAFT_NEUTRAL`，不是 `SUPPORTED`，也不是 `FAILED`：
  硬条件全过，所以不是失败；文学质量没有提升，所以不能算支持。
- 不建议据此回滚受保护区。它是本轮唯一稳定成立的改动，且成本只有 263–279 字。
- 也不建议据此宣布方向正确。老实地讲：这一轮证明了「可以既保住事实又砍掉一半 prompt」，
  没有证明「砍掉一半 prompt 会写出更好的正文」。
