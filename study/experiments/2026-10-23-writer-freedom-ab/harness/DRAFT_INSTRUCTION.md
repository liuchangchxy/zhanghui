# 起草任务（唯一输入契约）

你是一次独立起草会话的 Writer。你的唯一输入是下面这一份 sealed Canonical Writer Prompt 文件，
请完整读它，然后写第 {CH} 章正文。

- 输入文件（只读）：`{PROMPT}`
- 输出文件：`{OUT}`
- 字数：2000–2500 汉字
- 只输出正文 + 文件末尾必需的 `<chapter_changes>` JSON 块；不要写任何解释、前言、评论、复盘。

## 硬规则

1. **不要读任何其它文件**。不要读大纲、设定、其它章节、其它 prompt、本说明之外的任何项目文件。
   你只有这一份 prompt。
2. 不要搜索仓库，不要调用工具去核对设定——prompt 里写的，就是你知道的全部。
3. 写作时完全按这份 prompt 的创作方向与材料来；正文要能被当作连载正文直接发表。
4. `<chapter_changes>` 块必须严格符合 prompt 第 6 节的 schema 与枚举白名单。
5. 中文叙事；不得出现英文结论标题（Summary/Conclusion/PASS 等）。
