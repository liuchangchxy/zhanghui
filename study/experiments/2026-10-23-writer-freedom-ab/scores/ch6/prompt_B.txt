## 3. 创作方向
**一、开篇委托**

《海港旧信》第6章《修设备的人》。一句话：许知远必须先把手里那点东西交出去，才能从一个怕丢活的外包检修工嘴里，问出潮位站那批通信设备到底是什么时候换的。

**二、这章的故事**

前情。10月9日周五，许知远在旧潮位站清点十三项资产，在《值班记录本》封底夹层里发现一张对折的纸，只有一行字：日期 2016年3月17日，编号 临潮07；同一本记录本中间偏后一页，还有一行墨色更新、行距不对的手写。当天下午他去查这个日期：事故调查卷宗的目录卡片标着“限制查阅、须科级以上授权”，背面铅笔字写着归档单位市海事局，卷宗编号里带着 0317；他没递调阅申请，改去地方志办公室和报社旧报库，用公开渠道核到三处记载——《临港市志》大事记一行、3月18日旧报三行简讯（“昨日凌晨”）、3月24日同一位置的后续“事故原因查明，系通信设备故障所致”。三处都没有地点、没有船名、没有伤亡、没有署名。他只抄，不复印、不拍照，也一直没上报。傍晚他回站补核完第十一至十三项，第十项那台通信终端老周不许碰，是外包检修工梁沐掀开外壳后他才抄下铭牌：型号 TX-2015，编号 TX-2015-086。他说了句“这机器看着比站里别的设备新”，梁沐一边拧螺丝一边回了句：“那批设备啊，是事故之后统一换的。”

第3到第5章按大纲已经发生（目前只有大纲、没有成稿，写到它们时按大纲的事实走，别凭空补对白）：老周把他来废站的事报给了档案科，科长口头警告他别掺和海事的事，他回头发现自己的调阅驳回记录被人删了；他去追日志，请求被转到港务调度郑培手上，郑培客气得滴水不漏，送他出门时说了句“许工，十年前的月报，你手上应该也有一份吧”；他去调自己十年前经手归档的潮位观测月报，发现事故当天那一页没了，封底还有一行不是他笔迹的铅笔小字。他现在知道两件事：有人在盯着他，而且他自己经手的东西也被人动过。清点单和两张空着的差异说明还压在他手上——差异说明要一份可参照的原始登记才能填，这正好给了他一个回站的理由。

他为什么非问这个不可。公开记载把事故原因一句“系通信设备故障所致”就结了；而站里那台通信终端的型号和编号他都亲眼抄过，梁沐上次那句“事故之后统一换的”还悬在那儿。“事故之后”到底是多“之后”——三天、三个月还是半年——是他现在唯一能抓住、又不必惊动任何人的一个刻度。这不是灵感，是他手上仅有的两条能对得上的东西。

现场怎么走。10月14日周三下午，他借着补差异说明的由头又进了站。开场得先用一两句把前一晚带过去，不要直接跳。老周在门口，签进站时间，照例盯着。梁沐在站里做拆除前最后一轮检修，工单就摊在旁边。许知远这一场想要的非常具体：那批设备换的准确时段，以及梁沐凭什么这么记。挡住他的不是某个人，是三样东西叠在一起——老周就在视线里，梁沐的工单是港务集团派的，而“港务系统内部的事”对一个外包工来说等于饭碗。梁沐不会撒谎，他只会把话缩回工单里去：看工单、按批次、我们只管换不管登记。许知远很快发现，用问的方式一个字也问不出来，因为梁沐没有一套能安全说这些事的语言。于是他被迫做一个他从来不做的动作：先开口，先交底。他把抄下的型号和编号给梁沐看——这一条梁沐当场就能自己走到机器边上核对，所以不是空口白话；接着他把日期说出来：2016年3月17日。这是他手上最敏感的东西，说出去就等于把自己的调查方向交给一个刚认识的人。他再补一句承诺：不把梁沐的名字写进任何记录。对一个把“记录”当命的人来说，这句话的代价比丢工作更难受。梁沐核对完编号，确认这人不是来查他的，才按自己的规矩回了一条——整批换的、大致在哪个时段、凭什么这么记（批次号是连着的，同批不止这一台）。这条必须和许知远原来的默认不一样，让“事故之后”这四个字松掉。收束的那一拍：两人把话说清楚——往后只交换能各自去核的东西，不写名字，不写来源。合作就是这么立起来的，不是靠交情。

这一场结束后，实质变化有三样，缺一不可：他拿到了一个可查的时间刻度（不是"听说过"，是"能自己去核"）；他第一次把判断权分给了别人，而且很不习惯；他和梁沐之间多了一条只走可验证信息的通道——这条通道第8章要用来复核推算，第16章要用来留门，本章只要把它立住，不要提前用它办事。

必须落地的三拍（大纲里标作 CBN / CPNs / CEN，审查看首拍与收束拍有没有真的发生）：开头他试探梁沐，对方把话缩回工单；中间他交出自己查到的东西换信任；结尾两人定下只交换可验证信息的规矩。第一拍和第三拍不能省。

不能碰的：不引入任何超自然力量或系统；不许他凭直觉或"感觉不对"就跳过证据链；不许出现他不可能知道的信息——梁沐说的每一条都得有梁沐能指认的出处，许知远接的每一条都得是他自己看得到的东西。另外，本章不揭开事故真相，也不许把“检修期”和“通信设备故障”这两件事连起来说破因果——那是后面的事，这里只让这两句话并排站着。本章不新埋伏笔，推进的是“那批设备是事故之后统一换的”这一条（第17章才收），不回收任何一条。

跨章约束：时间是10月14日周三下午，章内约三小时，距旧潮位站11月8日拆除还有二十五天，倒计时不许跳；从第5章的10月13日上午跨过来，要用一两句把这一夜带过去。本章不推进郑培线、不推进老周上报线、不推进缺页线，只让它们作为背景压力存在——老周站在门口这件事本身就是压力。

一处需要留意的接续：大纲里本章末尾那句问题指向“检修期为什么会留下记录”，但下一章定好的动作是用公开潮汐数据独立复算当夜潮位。所以本章收尾时，把问题落在“官方那个潮位数是从哪来的”，不要把“去查检修记录”写成下一章已经定好的事。

**三、这章的人物**

许知远。三十四岁，档案管理员，工龄十年，入职在事故后第三个月。进本章时他手上压着没交的清点单和两张空白差异说明，被科长口头警告过，知道自己被盯着，还有一份自己经手归档、缺了事故当天那页的月报。他的驱动力不是好奇，是“这条线只有我能对上”：公开记载说原因是通信设备故障，站里这台通信终端是事故之后统一换的——更换时间就是他能抓住的第一个刻度。他本章的作用是破自己的规矩：一个只信纸面、只说核过的话的人，必须先把没核过的东西说出口。说话倾向：短句，问得很具体，一旦要交底就先把话说得像一份记录；不解释自己为什么问。

梁沐。外包检修工，港务系统最外围的人，停工就断收入。他在站里做拆除前最后一轮检修，知道这批设备的来历，上次也随口漏过一句。他不是坏人，也不神秘——他就是“系统性的沉默”长在人身上的样子：怕丢活，不想惹事，也不想被人当傻子。他本章的作用是让许知远第一次必须靠别人。说话倾向：只用工单上的词挡——“看工单”“按批次”“我们只管换不管登记”；一旦决定说，说得极短，而且带条件。不要给他“其实我一直在等你说这句话”的暗示，不要美化也不要反转他。

老周。六十上下，看护员。他本章不上场说话，但一直在场：门口、脚步声、平房的灯。作用是把梁沐的嘴按住——只要老周看得见，梁沐就不说。许知远要谈话，先得解决“老周看得见”这件事。说话倾向：流程句，短，不解释。

**四、怎么写更顺**

这一章是冷、克制、信息靠对白和物件走的一场戏。基调是高压克制：三个人站在一座二十五天后就要推平的站里，谁都没有提高声音，但每一句都在掂量代价。不要写成两个人交心，也不要写成审讯——这是两个底层的人在用各自唯一会的语言互相确认对方靠不靠得住。

节奏上是先立规则后破局，本章的“规则”就是梁沐的规矩：只谈工单，只谈能查的。前半段让这条规矩把许知远挡死，挡到他不得不换办法；中段他先破自己的规矩（先给、先承诺不记名字）；后半段梁沐按自己的规矩回一条。破局不是谁被说服了，是两个人找到了一个都能接受的交易方式。

具体落笔：八成信息交给对话，但对话要具体到型号、批次、时段、工单，别写成空对空的试探。许知远的内心只在动作里露——抄、核、把本子合上、笔帽按上、指腹压一下怕墨没干。不要写“他心想”。每一条新信息落地时都要有一个当场能指认的出处，读者要能自己核；数字和日期要具体，但只能是他看得到的那些。老周的存在要一直能被感觉到，别只在开头出现一次就消失。章末那句之后，给一个很短、很克制的反应就够，不要长篇心理总结，也不要替下一章做决定。只写真正发生的动作——上一章出过“提交记录里写了开机、正文只写了打开外壳”这种不一致，这次凡是写进正文的动作都得真的发生。

另外三条提醒：不要让梁沐一口气把答案说完，也不要让许知远凭一句“直觉”把两头接上；不要给梁沐安排一段解释自己为什么怕的独白，他的怕要落在工单和停顿里；不要在本章说破任何因果，本章只负责把矛盾摆好。

审查上的趋势：第2章零阻塞，两条建议——一是章末没有显化“下一步要干什么”（可接受，不必为清零硬加自白），二是正文动作与提交记录不一致。所以这一章把动作写实、把状态写实就够了。

**五、收在哪里**

本章的回报是实的：许知远拿到了一个能自己去核的时间刻度——那批设备是整批换的、大致在哪个时段、凭什么这么记；他也第一次把判断权分给了一个刚认识的人。他付出的东西很具体：把手上最敏感的日期说了出去，还承诺不把梁沐的名字写进任何记录——对一个靠记录活着的人来说，这比丢工作更难受。梁沐得到的是一个不会把他写进档案的人，和一条“只换能互相核的东西”的规矩；他也把自己的风险押了上去。

而真正压在章末的那句话是梁沐说的：你查的那天，潮位站应该是在检修期，不该有记录。这句话把许知远一直默认的前提掀了一下——他此前所有的推演都建立在“那天有记录、只是记录被人改过”上；现在有人告诉他，那天本来就不该有记录。于是读者此刻最想知道的很具体：那些记录是谁做的？官方那个“通信设备故障”的结论，又是从哪一份数上来的？这个问题不是凭空另起一个，它是本章两件事撞在一起的结果——一个能查的时间刻度，加一句“那天不该有记录”。

因为这件事，读者接下来想看的也更具体了：他既然不能信档案里的那个数，就得自己去算一遍。

## 本章创作方法
（这些是写作原则，不是执行步骤；具体动作、对白和细节由你根据本章材料自己决定。与 Canon、作者意图、本章禁区冲突时，一律以后者为准。）
1. 人物主动性 —— 本章值得注意：许知远不能只是问、听、记。让他先用常规问法试一次，被梁沐用「看工单」挡回，再自己决定把抄下的 TX-2015-086 和 3月17日 这个日期推过去——这一步必须让他难受，因为他清楚说出去就收不回。梁沐闭嘴也有他自己的账：工单是港务集团派的，名字落在哪张纸上他就少一份活。老周站在门口不是布景，是逼许知远另找说话时机的那道墙。
   - 每一场都问：人物现在想要什么？他为了得到它，主动做了什么？如果删掉他的选择，剧情还成立吗？如果成立，这个人物就是被动的。
   - 选择必须有代价：选 A 就失去 B。没有代价的选择只是信息确认。
   - 人物可以判断失误。失误要产生后果，而不是被下一段轻松修正。
   - 配角也要有自己的目标和小动作；不要让他们只负责回答主角的问题。
   - 信息通过人物的行动被发现，而不是通过别人转述给他。
   正例：科长让他别再掺和海事档案。他当面答应，转身却用自己的工号去查那条调阅记录——他知道这会留下痕迹，也知道自己已经没有别的路。这个选择同时推进了剧情和人物。
   反例：同事告诉他档案被人动过，他觉得很奇怪，决定明天再看看。整章他没有做任何会被记录、被阻止或需要承担后果的事。
2. 对话潜台词 —— 本章值得注意：梁沐不正面拒绝，也不解释自己怕什么——他只用「看工单」「按批次」「我们只管换不管登记」把话缩回去，怕要落在拧螺丝的手停一下、抬头瞟门口这些地方。许知远交底时话说得像一份记录：先报型号编号，再报日期，再承诺不把梁沐的名字写进任何记录；不解释自己为什么问。老周整场不说话，签进站时间、在门口走动、把登记簿合上，每次让他显形都该让梁沐的嘴再闭紧一点。
   - 越重要的情绪越不要在第一句说破。让人物说出口的话保持克制，真实态度放在他回避什么、停顿在哪里、手上在做什么、哪个问题没有回答。
   - 每段关键对话至少承担一种功能：给新信息、造冲突、做决定、改关系、推行动。删掉不影响情节的台词。
   - 同一场里，各人的回避方式和攻击方式要不同：有人用流程挡，有人用沉默挡，有人反问。人物独特的说话方式本身另有专项，这里只管“他为什么不肯直说”。
   - 对话是回应，不是轮流发言。允许打断、追问、抢话、答非所问。
   - 不让角色在对话里解释世界观或背景；重要信息通过动作、发现、冲突展示。
   正例：“档案科批了吗？”老周问。
   “路过。”
   “路过也要登记。”老周把笔推过来，笔尖停在日期那一栏，“写今天。”
   他写了，又停住。“潮位尺什么时候换？”
   老周看了他一眼，把登记簿合上。“你问这个干什么。”
   反例：“我其实是来这里调查二十年前那场事故的，”他说，“因为档案被人动过，所以我必须找到真相。”
   “我明白了，那你一定要小心，背后的人很危险。”老周说。
3. 视角与叙事距离 —— 本章值得注意：只写许知远看得见听得到的：梁沐低头时后颈的汗、工单摊开的那一角、老周在门口换了个站姿；读者自己去判断他们在想什么。别写「梁沐其实也不想惹事」「老周心里明白」，也别让叙述者替两人说明这场谈话意味着什么。许知远的推断要写成推断——「他猜梁沐是在等老周走开」，而不是事实。章末那句「该在检修期」之后，他做一个动作或起一个念头就停，不解释这句话动摇了他原来的哪个前提。
   - 每一句先问：这是谁在感知？他此刻能看见、听见、知道什么？
   - 人物不知道的事，不能由叙述者直接宣布。要么让他从可见迹象里推断（允许推错），要么留给读者。
   - 别人的内心只能从外部读：表情、停顿、手上的动作、说了什么和没说什么。不写“老周心里其实很怕”。
   - 人物自己的判断要写成判断，不是事实：“他猜老周在拖时间”，而不是“老周在拖时间”。
   - 距离默认贴着人物的眼睛和手。需要交代时间跨度或环境全貌时再拉远，拉远之后要回到人物身上；同一段里不要来回跳。
   - 作者不替人物解释这一句的意义（“这句话说明……”“这意味着……”）。让读者自己接上。
   - 这些是写之前的边界检查，不是正文结构。读者不该看出“这里在守视角”，只该觉得自己只能知道这些。
   正例：老周把登记簿翻回上一页，指尖在某一栏停了一下，又继续往下翻。许知远只看见那栏的日期是三月，后面的字被他的拇指盖住了。“找什么？”他问。“没找。”老周把本子合上，压在手肘底下，“你要是没事，就回去吧。”回去的路上他想，那一下停得不像随手翻。也可能只是纸粘住了。
   反例：老周心里一沉，他知道这个年轻人已经查到了关键处，再让他翻下去，二十年前的事就瞒不住了。许知远也明白老周在害怕。两人各怀心事，气氛变得微妙起来。

2. 正文末尾必须严格附带合法的 <chapter_changes>...</chapter_changes> 结构化提案块；
   提案块必须是合法 JSON 对象，包含以下 8 个标准顶级字段：
   - character_state_changes (对象数组): [{"character_id": "角色名", "new_state": "状态变化", "importance": "normal"}]
   - new_plot_points (对象数组): [{"context": "情节发展描述", "importance": "normal"}]
   - foreshadowing_actions (对象数组): 若本章无既有伏笔操作填空数组 []
   - location_state_changes (对象数组): 若无填 []
   - faction_state_changes (对象数组): 若无填 []
   - time_progression (对象或 null): {"time_period": "时间进展描述", "importance": "normal"}
   - item_transfers (对象数组): 若无填 []
   - unresolved_questions (对象数组): [{"question": "章末悬念或未决问题"}]
   注意：各数组元素必须为 JSON 对象（严禁输出纯字符串数组），若无变更请使用空数组 []；
   【状态变化 vs 首次登场核心契约】：
   - 新角色/新地点/新物品可以正常出现在正文中；
   - 首次出现的新实体不属于 state change，后续由 Data Agent 根据最终正文独立提取，并在 ChapterCommit acceptance 后进入正式账本 projection 入库；
   - 提交前，严禁把尚未入库的新角色/新实体写入 character_state_changes, location_state_changes, faction_state_changes, item_transfers 等状态变更字段（若无已有实体变更，填空数组 []）；
   - new_plot_points.involved_characters 当前受 R3 门禁约束，只填写 Canon/context 中【已经存在】的角色，严禁填写尚未入库的新角色；
   - 新角色参与的事件仍完整记录在 new_plot_points 的情节描述（context 或 description）中；
   - 极短示例：正文首次出现新角色“巡查队长赵崇”与新地点“地下档案修复室”：

   - item_transfers.new_status 只能取: "active", "lost", "destroyed", "sealed"；
