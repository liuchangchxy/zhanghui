## 0. 结论先行

**判定：PARTIAL。**

- **文学层：泛化成立。** 六章全部严格偏 B：两位不同模型族评委、每章两遍位置反转，
  六维合计 **72/72 个稳定判定全部指向 B**，0 SPLIT、0 TIE、0 A 胜。
  `READING_APPEAL` 与 `LOW_AUTHOR_EXPLANATION` 均 12/12 B；需要保住的
  `SENTENCE_NATURALNESS` 与 `SCENE_IMMERSION` 也均 12/12 B。
- **内容层：没有 HARD 级损失。** 没有改变事件结果、知情状态、物品归属、数字/日期/编号、
  专业术语；没有删掉唯一的下一步动作、调查方向或时间地点硬限制；没有长度违规。
  上一轮 ch04/ch05 那种“把承担下一步功能的信息一起删掉”的问题没有重演。
- **但不是无损。** 人工逐段检查发现三处可定位的 SOFT 损失：
  ch02 删掉了独立成段的章末钩子“明天。”；ch06 删掉了“不是问。”和本章情绪结算句
  “他换到的，比交出去的少。”；ch09 删掉了结尾唯一的感官记忆句。
  这些信息大多仍可从保留下来的对白/动作推出，但它们承担文学功能，不能算“零损伤”。
- **因此：** 预注册的文学条件全部满足，事实/功能层内容保全也满足；但“不损坏内容”
  在章末钩子与文学承载层不完全成立。按 `SAMPLE_SELECTION.md` 的 PARTIAL 定义
  （“少量可定位的内容损失”），判 **PARTIAL**，不判 PASS，也不判 FAIL。

## 1. 问题与设计

PR #66 在 ch03 / ch04 / ch05 / ch08 上得到 48/48 稳定偏 B，但这四章参与了五条原则的提炼，
属于开发集。本轮唯一目标：

> 冻结五条原则，只在没有参与规则提炼的章节上测试，判断该机制是否真的能泛化，
> 并且不损坏内容。

设计：

- A = Zhanghui 当前 final（去掉封包指纹）。
- B = 同一个 A 经过一次冻结编辑器处理。
- Jarvis 正文从不进入编辑器输入，也不进入 A/B。
- 编辑器不看 PR #66 的 edited 输出，不看 held-out 章节的任何盲评结果。
- 每章只生成一次 B；只在空输出/截断时做技术性重试。
- 长度低于原文正文 90% → `EDITOR_REJECT_LENGTH`，不补字、不重跑、不做 A-vs-A 盲评。

## 3. 编辑机制

五条原则逐字复用 PR #66。只新增三个来自上一轮真实失败的护栏：

1. **保护推进信息**：不得删除明确的下一步动作、调查方向、时间/地点硬限制、章末钩子、
   影响后续行动选择的信息；可以删它们前后的解释性总结。
2. **保护必要推理连接**：“具体数字/物件/证据 → 关键结论”若不能由读者立即唯一推出，
   必须保留连接句；可压缩措辞，不可整段删除。
3. **长度硬约束**：正文低于原文 90% 直接判编辑失败。

编辑器：`group/mac-deepseek4.1-gpt[1m]`，temperature 0.4，max_tokens 16000。
Prompt 与全部输入的 SHA-256 在 `FREEZE.json`；Prompt 在 `prompts/editor_zh_heldout.md`。

## 7. 成功标准逐条

按 `SAMPLE_SELECTION.md` 预注册标准：

1. **至少 4/6 章 OVERALL 多数稳定偏 B**：6/6 严格偏 B → **满足**。
2. **RA 与 LAE 总体明显偏 B**：两维均 12/12 B，A=0 → **满足**。
3. **SN 与 SI 没有系统性偏 A**：两维均 0 A、12 B → **满足**。
4. **没有重要推进信息、关键推理链、专业术语或事实层损失**：
   没有 HARD；但 ch02 删掉了预注册护栏明确列为“章末钩子”的“明天。”，
   按严格口径视为文学承载层的可定位损失 → **不完全满足**。
5. **没有长度违规后仍被采用的 B**：六章均 ≥92.5%，无拒绝 → **满足**。

**结论：1、2、3、5 满足，4 在“无 HARD 事实损失”意义上满足、在“章末钩子/文学承载无损”
意义上不满足。** 因此不是 PASS；因为文学收益稳定且没有 HARD 内容损失，也不是 FAIL。
判 **PARTIAL**。

## 8. 收益与回归

### 8.1 稳定收益

- 六章全部偏 B，且不是靠某一种章节类型：ch01（日常修复+发现）、ch02（钥匙交接与试探）、
  ch06（十年前回忆）、ch07（材质鉴定与谈判）、ch09（开盒与暗道）、ch10（三方分歧）
  都出现同向收益。
- 收益来源与 PR #66 一致：删意义总结、删对白翻译层、删重复复盘、让章末落在已有动作/画面上。
- 收益没有以 SN/SI 为代价：这两维也是 12/12 B；文本指标上句均长基本不变，
  对话占比略升（如 ch07 0.333→0.360），段落数只小幅下降，没有压成摘要。

### 8.2 可定位回归

- ch02 章末“明天。”：最明确的护栏 1 失败。原则 4（收在已有画面上）与护栏 1（保护章末钩子）
  在这一处直接冲突，编辑器选择了原则 4。
- ch06 “不是问。”与“他换到的，比交出去的少。”：评委把删除当作优点（“更有余味”），
  人工检查认为这是潜台词与情绪结算的损失。这是“盲评更喜欢”与“内容承载”分歧的典型样本。
- ch09 结尾感官句：评委认为“拖泥带水的感官补笔”应删；人工检查认为这是唯一的结尾感官记忆。
- ch07 谈判动作“手没把它推回来”：评委把“乔宁没有推回钥匙的动作”说成 B 的优点，
  而这句话在 B 中已被删；评委可能是从剩余动作读出了同一信息。这说明评委证据不能替代逐句内容核对。

### 8.3 机制判断

- 五条原则在完全未参与提炼的六章上仍然稳定产生文学收益；不是只对 ch03/4/5/8 有效。
- 三个护栏把上一轮的 HARD 内容损失压到 0，但仍不能保证文学承载层无损。
- 下一轮如果继续，只需要补一条窄护栏：**章末最后一段如果是独立成段的短句/单词钩子
  （如“明天。”），不得删除；情绪结算句与结尾感官句需逐句保留判断**。
  不需要新架构、新 Agent 或语义门禁。

## 9. 限制

- 单一书、单一 run（2026-10-29）、六章，每章只编辑一次。
- 只有两位评委、两个模型族；稳定判定只代表这两位评委在位置反转下的一致，不等于人类读者共识。
- 编辑器与 PR #66 使用同一模型与同一 temperature，结果不能外推到其他模型。
- 盲评只给文本，不给大纲、前章或后续；评委无法判断某个删减是否承担后文功能。
- 长度普遍下降 2%–7.5%，评委被要求忽略长度差异，但长度仍可能是隐含线索。
- ch10 没有下一章开头，章末推进保护在该章弱于其他五章。
- ch01 / ch02 / ch06 在 PR #66 的归因阶段被作为补充材料读过；虽然五条原则不由它们提炼，
  严格意义上的“完全未接触”只对 ch07 / ch09 / ch10 成立。
- 72/72 过强，存在评委风格先验；评委理由中有至少一处把已删内容说成 B 的优点（ch07）。

## 10. 收口回答

> **PR #66 的五条文学编辑原则，在完全没参与规则提炼的六章上，是否还能稳定提高文学性，
> 同时不损坏内容？**

**能稳定提高文学性；但不能说完全不损坏内容。**

- 六章、两位评委、位置反转、六维合计 72/72 稳定偏 B，文学收益可泛化。
- 事实/功能层内容没有 HARD 损失；上一轮的 ch04/ch05 式误删没有重演，长度也全部达标。
- 但章末钩子、情绪结算句、结尾感官记忆出现少量可定位的 SOFT 损失，
  所以不是零损伤的 PASS。
- 结论：**机制值得保留，但按 PARTIAL 处理**；正式集成前只需补一条“章末短钩子/情绪结算句
  不得删”的窄护栏，不需要改架构。
